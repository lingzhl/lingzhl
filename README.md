## Featured Project

### [E-commerce Generative Recommendation System](https://github.com/lingzhl/ecom-genrec)

OneRec-style reproduction roadmap based on Amazon Reviews 2023:

- Semantic item IDs with KMeans SID and RQ-VAE-style residual quantization.
- Qwen2.5-1.5B multitask SFT for sequence recommendation, feature alignment, and history fusion.
- GRPO post-training with Hit, NDCG, Category, Valid SID, Diversity, Novelty, and Reasoning rewards.
- Evaluation with HR@10, NDCG@10, Catalog Coverage, Novelty, Valid SID Rate, cold-start subsets, and ablations.

Current goal:

```text
1.5B reproduction first -> 7B/14B scale-up later
```
